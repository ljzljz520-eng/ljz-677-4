# 教育成绩大表导入与市级平台分批上送系统

老师上传几万条成绩（Excel/CSV）→ 系统校验 **学号 / 课程 / 分数 / 考试批次** →
分批上送市级平台 → 平台异常行可下载、修正后重传。任务全部持久化在服务端，
**浏览器刷新、关闭甚至服务重启都不丢任务、不丢进度**。

## 启动

```bash
npm start          # 默认 http://localhost:3000
PORT=3100 npm start
```

首次启动自动建库并写入演示主数据：

| 数据 | 规模 | 说明 |
|---|---|---|
| 考试批次 | 4 个 | 202603 等，上传时必须选择，行内批次须与所选一致 |
| 课程 | 9 门 | 语文/数学/英语…，支持代码（CHN）、别名（道法/政治） |
| 学生学籍 | 6000 人 | 10 位数字学号：年份(4)+班序(3)+班内序号(3) |

## 使用流程

1. **选考试批次** → 拖入 `.xlsx/.xls/.csv`（≤50MB，支持 GBK 编码 CSV）。
   页面提供「下载导入模板」和「生成 5 万行示例大表」。
2. **后台异步解析校验**：上传接口秒回任务 ID，页面轮询进度。
   校验规则：
   - 学号：必填、10 位数字、须在学籍库
   - 课程：必填、须在课程目录（按名称/代码/别名匹配）
   - 分数：必填、数字、0–100（支持 0.5）
   - 考试批次：必填、须存在且与所选批次一致
   - 表内查重：同学号+同课程+同批次重复判定为异常
3. **开始分批上送**：每批 200 行，模拟平台 4.7% 确定性业务拒收（附具体原因）、
   偶发 503 限流（客户端退避重试 3 次）；网络故障自动暂停，**进度保留**可继续。
4. **异常处理**：
   - 校验异常 / 平台拒收均可「下载异常行」（xlsx，末列附异常原因与原始行号、带自动筛选）；
   - 修正前 4 列后点「修正后重传」，自动以**子任务**身份关联原任务。
5. **历史任务**：任务与全部行明细落 SQLite，列表按 全部/进行中/待处理/已完成 筛选；
   详情页 hash 路由（`#/task/123`），F5 刷新直接回到该任务。

## 服务重启恢复策略

- 解析中重启：任务标记为「解析失败」，请重新上传原文件；
- 上送中/中断重启：按已落库行状态回算为「上送中断」，已成功的行不会重发，点「继续上送」即可。

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/batches` | 可用考试批次 |
| GET | `/api/template?batchName=` | 导入模板 |
| GET | `/api/sample?count=50000&batchCode=` | 示例大表（含各类异常行） |
| POST | `/api/tasks` | multipart 上传建任务（file/batchCode/name/parentTaskId） |
| GET | `/api/tasks` / `/api/tasks/:id` | 任务列表 / 详情 |
| GET | `/api/tasks/:id/rows?filter=&page=&size=` | 行明细分页 |
| POST | `/api/tasks/:id/send` | 开始/继续分批上送（幂文） |
| GET | `/api/tasks/:id/errors` | 下载异常行 xlsx |
| DELETE | `/api/tasks/:id` | 删除任务（处理中禁止） |

## 结构

```
src/db.js        SQLite 建表 + 主数据
src/parser.js    Excel/CSV 读取（编码识别、表头映射）+ 四类校验 + 查重
src/platform.js  市级平台模拟客户端（确定性拒收 / 503 限流）
src/worker.js    分批上送、退避重试、中断恢复
src/files.js     模板 / 示例 / 异常行导出
src/server.js    Express 路由
public/          单页前端（原生 JS，3 秒轮询，hash 路由）
```
